# grit-wasm-bindings

This package is used to generate the bindings for using Marzano from the browser.

This entire package is generated by building `crates/wasm-bindings` with [`wasm-pack`](https://rustwasm.github.io/wasm-pack/). **DO NOT MAKE CHANGES TO THIS PACKAGE DIRECTLY**. Instead, make changes to `crates/wasm-bindings`, then run:

```shell
cd crates/wasm-bindings
wasm-pack build --target web
```

and copy `package.json` and the `grit_wasm_bindings*` files from `crates/wasm-bindings/pkg/` to this directory.
